Lanceur Ibiza - projet Android Studio

1. Android Studio > Open > choisir ce dossier (IbizaLauncher).
2. Laisser Gradle synchroniser (Android SDK 34 requis, Android Studio le propose).
3. Emulateur conseillé : tablette paysage 1024 x 600 (ou 1280 x 720), API 28 à 34.
4. Run 'app'. Sur l'émulateur : touche Accueil > choisir Ibiza > Toujours.
5. Pour tester portes et radars sans voiture : appui long sur l'horloge > Réglages du lanceur > Simuler.

L'interface web est dans app/src/main/assets/www (HTML/CSS/JS). Après modification, relancer Run.

  Toucher la pochette ouvre l'appli qui joue (radio comprise).

  et pastille « Révision » sur l'accueil. Sources lues, dans l'ordre :
    1. diffusions du système : le lanceur analyse les applis CAN / voiture / lanceur d'origine du poste, y relève les actions d'Intent et s'y abonne ;
    2. propriétés système (getprop) ;
    3. journal système (logcat), si autorisé une fois par adb :  adb shell pm grant fr.ibiza.launcher android.permission.READ_LOGS

       (elles sont gardées au redémarrage), toasts « Porte ouverte » compris.
  Réglages > Données CAN du poste : « Analyser » (liste les applis et actions trouvées dans le journal) et « Copier les APK CAN »
  (copie dans Android/data/fr.ibiza.launcher/files/apk, à m'envoyer avec ibiza_diag.txt pour décoder exactement le format du poste).

Version 1.8 (après analyse de l'APK CarCan com.hcn.autocan v43)
- Constat : CarCan ne publie ses données d'ordinateur de bord (carburant, km, batterie, régime, frein, ceinture) qu'à son propre
  écran. Son service « ICustomDataServices » n'envoie rien. Seuls portes, clignotants, radars, vitesse et angle volant sont
  publiés en direct (propriétés persist.vendor.cem.*).
- Ordi > « Actualiser » : ouvre CarCan, touche « CarInfo », lit l'écran puis revient sur le lanceur (≈ 2 s).
- Réglages > Lecture auto de l'ordinateur de bord : au démarrage (défaut), ou démarrage + toutes les 15 min (seulement quand
  l'accueil Ibiza est affiché, jamais par-dessus CarPlay), ou désactivée.
- Vitesse : lue sur le CAN quand le poste la fournit (sinon GPS).
- Clignotants affichés à côté de « Ibiza » (persist.vendor.cem.light0 / light1).
- Ordre des portes confirmé dans CarCan : cardoor1 AVG, 2 AVD, 3 ARG, 4 ARD, 5 coffre.
